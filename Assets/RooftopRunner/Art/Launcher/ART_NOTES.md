# Rooftop Runner launcher icon

Created with the built-in image generation tool. Original artwork is saved as `RooftopRunnerIcon.png`. Unity imports it at up to 1024 pixels and generates the Android launcher sizes. A transparent foreground layer lets Android apply its own circle or squircle mask to the full-bleed background illustration. No corner mask is baked into the source.

To reapply: switch the editor to Android, then use Rooftop Runner > Apply Launcher Icon. The default application icon is also assigned. This project targets Android API 26 and newer, using adaptive icons.
